bool parse_bypass(const std::string &text, const std::string &overlay_cidr, std::vector<BypassRule> &rules, const char *tag)¶

Parse the text of a bypass file.

Every line must parse for the call to succeed; the first bad line is reported on stderr with its number. A route prefix must not be 0.0.0.0/0 (that would undo the default route through the TUN) and must not overlap the overlay prefix (that would take the overlay off the TUN).

Parameters:

  • text – The whole file.

  • overlay_cidr – The overlay prefix, a.b.c.d/n.

  • rules – Receives the rules, in file order, on success.

  • tag – Log prefix such as “[Agent]”.

Returns:

true when every line parsed.

bool load_bypass_file(const std::string &path, const std::string &overlay_cidr, std::vector<BypassRule> &rules, const char *tag)¶

Read and parse a bypass file.

A file that cannot be opened is an error, so a wrong path cannot silently leave a machine without its exceptions.

struct BypassRule¶
#include <bypass.h>

The bypass file of an agent (VNET_BYPASS_FILE): what stays on the physical network while the agent is joined.

Blank lines and lines starting with ‘#’ are ignored. Three kinds of lines:

*   route a.b.c.d/n
*     The prefix keeps going through the physical gateway instead of the
*     TUN, and under lockdown it is allowed in both directions on every
*     port. A bare address is a /32.
*
*   out <iptables arguments>
*   in  <iptables arguments>
*     A rule appended to the lockdown chain VNET_OUT or VNET_IN, before
*     the final DROP, exactly as written: "in -p tcp -s 10.20.0.0/16
*     --dport 22443 -j ACCEPT". The arguments are split on whitespace and
*     handed to iptables without a shell. Without lockdown they do
*     nothing.
*
*   out6 <ip6tables arguments>
*   in6  <ip6tables arguments>
*     The same for IPv6, which lockdown otherwise blocks entirely.
*

bool send_protobuf_packet(int sock, vnet::protocol::PacketType type, const google::protobuf::Message &msg, struct ssl_st *ssl = nullptr)¶

Send a protobuf message with the 6-byte packet header.

Wire format: [4-byte payload_size (network order)] [2-byte packet_type (network order)] [protobuf payload bytes]

payload_size = sizeof(packet_type) + protobuf_size but we store it as just protobuf_size since the header struct stores both fields and NetQueue reads header first.

IMPORTANT: payload_size in the header is the number of bytes AFTER the 6-byte header, matching NetQueue::process().

bool read_protobuf_packet(int sock, vnet::protocol::PacketType expected_type, google::protobuf::Message &msg, struct ssl_st *ssl = nullptr)¶

Read a protobuf message with the 6-byte packet header (blocking).

Reads the full header, skips heartbeats, verifies the packet type, then reads and parses the protobuf payload.

Parameters:

  • sock – The connected socket.

  • expected_type – The type the packet must have; any other type makes the call fail.

  • msg – Receives the parsed payload.

  • ssl – The TLS session of the socket, or nullptr.

Returns:

true when a packet of expected_type was read and parsed.

bool run_program(const std::vector<std::string> &argv, const char *tag, bool quiet = false)¶

Run a program with the given argument vector and wait for it.

The program is found through PATH; no shell is involved, so the arguments are never interpreted.

Parameters:

  • argv – Program name followed by its arguments.

  • tag – Log prefix such as “[Agent]” for the failure message.

  • quiet – Discard the program’s output and log nothing on failure; for probes whose failure is an expected answer.

Returns:

true when the program exited with status 0.

bool env_int(const char *name, long min, long max, long &value)¶

Read an integer setting from the environment.

Unset: value is left unchanged and true is returned. Set and within [min, max]: value is updated and true is returned. Otherwise an error naming the variable is printed and false is returned.

std::string env_or(const char *name, const std::string &def)¶

Read a string setting from the environment, or def when unset.

bool valid_name(const std::string &name, size_t max_len)¶

A machine name: 1 to max_len characters from [A-Za-z0-9_-].

Agent names are limited to 10 characters, since “vnet-” plus the name must fit the 15-character interface name limit.

bool parse_cidr(const std::string &text, uint32_t &addr, int &prefix)¶

Parse “a.b.c.d/n”.
