Wire protocol¶

Organizers do not need this page to run an event. It is here to read a packet capture, or to check what a version change touches.

Framing¶

Every link is one TCP connection, wrapped in TLS when VNET_TLS=1. It carries frames:

+----------------------+------------------+---------------------------+
| payload size, uint32 | type, uint16     | payload (size bytes)      |
| network byte order   | network order    |                           |
+----------------------+------------------+---------------------------+

The header is 6 bytes. A payload is at most 65994 bytes (a 66000-byte buffer less the header); a frame that announces more closes the connection. IPV4_RAW carries an IPv4 packet as it is; HEARTBEAT has no payload; every other type carries a protobuf message defined in proto/mip.proto.

Rules a program enforces¶

  • A connection must identify itself (SWITCH_MIP, AGENT_MIP, AGENT_MRP, AUTH_CONNECT_TO_SWITCH or SWITCH_HELLO) within 10 seconds, or it is closed.

  • A second identification on an identified connection is refused.

  • A switch accepts tokens, routes and configs only on its conductor link.

  • A switch accepts IPV4_RAW only from an authenticated agent or a peer switch.

  • With TLS, the role in the peer certificate must match the role the connection claims.
