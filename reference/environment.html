Environment variables¶

The programs take their settings from the environment; under systemd, from the unit’s EnvironmentFile (/etc/vnet/conductor.env, switch.env, agent.env). The Programs column says which program reads a variable: C conductor, S switch, A agent.

An integer outside its range stops the program at start with [Config] NAME must be an integer between MIN and MAX, got 'VALUE'. A flag that is off by default is turned on by exactly 1; a flag that is on by default (VNET_TLS_ROLE_CHECK, VNET_CONFIG_HASH_CHECK, VNET_DEFAULT_VIA_TUN) is turned off by exactly 0.

Command line¶

conductor
switch <name> [auth_key] <port>
agent  <name> [auth_key]

Names are 1 to 10 characters for an agent, 1 to 32 for a switch, from [A-Za-z0-9_-]. Give the key in the environment rather than on the command line, where every local user can read it. The systemd units take the name and port from VNET_AGENT_NAME, VNET_SWITCH_NAME and VNET_SWITCH_PORT in the env file; the programs themselves do not read these three.

S A

A file whose first line is the key.

C

required

The auth file (Auth file). Read again on SIGHUP.

VNET_ADVERTISE_IP

S

the address the conductor sees

Address or host name that agents and other switches dial to reach this switch. Set it when the switch is behind NAT or has several addresses.

VNET_NETWORK

S A

::internet (S), vnet.internal (A)

Network name used to place agents on switches (Architecture). A switch on ::internet takes agents of every network.

Access list¶

Variable

Programs

Default

Meaning

VNET_CONFIG_PATH

C S

The switch config (Switch config). On the conductor: sent to every switch, read again on SIGHUP. On a switch: the config to start with, read again on SIGHUP; a config from the conductor replaces it. A switch with neither waits for the conductor’s.

VNET_CONFIG_HASH_CHECK

C

on

When the switches read their own files: refuse a switch whose config differs from the others’. 0 turns it off.

VNET_OVERLAY_CIDR

S A

10.0.0.0/8

The overlay prefix. Must be the same on every switch and agent.

Liveness and state¶

Variable

Programs

Default

Meaning

VNET_HEARTBEAT_SEC

C S A

10

Seconds between heartbeats on every link, 1 to 3600.

VNET_DEAD_SEC

C S A

30

Seconds without anything received before a link is closed, 1 to 86400; must be larger than VNET_HEARTBEAT_SEC. Use the same values on every machine.

VNET_DUMP_PATH

C, vnet-state

/var/vnet-dump.bin

Where the conductor writes its state dump.

VNET_DUMP_SEC

C

60

Seconds between dumps, 1 to 86400.

Certificates tool¶

VNET_CERT_DAYS (default 400) is read by vnet-certs: the validity of the certificates it issues.
